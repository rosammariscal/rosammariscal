## Featured project

### [cagr-growth-value-pipeline](https://github.com/rosammariscal/cagr-growth-value-pipeline)

A reproducible Python pipeline that scores equities on growth, value and quality using yfinance data. It computes multi-year revenue, net income and FCF CAGRs, adds a valuation overlay (P/E, P/B, FCF yield), applies eligibility gates and builds capped Top-N weights. Look-ahead and survivorship bias are documented, and the code is unit-tested.  
Personal research: a screening tool with no backtest and no performance claims. Not investment advice.

`Python` `pandas` `NumPy` `yfinance` `pytest`

## Other repositories

- [UnconventionalReservoirSimulatorLib](https://github.com/rosammariscal/UnconventionalReservoirSimulatorLib): Python code from my doctoral research. It is a 3D finite-difference simulator of gas flow to a hydraulically fractured well in shale, covering the hydraulic fracture, natural fractures and organic/inorganic matrix. It includes fractal (power-law) permeability and porosity, Caputo fractional derivatives, Forchheimer flow and Langmuir desorption, solved with Newton–Raphson.

Course notebooks (Spanish):

- [Predicción](https://github.com/rosammariscal/Predicci-n): multivariate time-series forecasting on Google Community Mobility Report data (Puebla, Mexico). Lagged-correlation input selection, then a multi-output random forest and an LSTM (Keras), both evaluated on a held-out period.
- [Clasificación](https://github.com/rosammariscal/Clasificaci-n): unsupervised classification of the same mobility series (Tabasco, Mexico) with lagged features, k-means and a self-organizing map.
- [RandomForest](https://github.com/rosammariscal/RandomForest): decision tree and random forest classifiers on the Pima diabetes dataset (scikit-learn), with tree visualization and Optuna tuning of the tree's hyperparameters.
- [Mecánica de Fluidos](https://github.com/rosammariscal/Mec-nica-de-Fluidos): Fluid Mechanics course (Petroleum Engineering, UNAM). Gaussian-mixture clustering of pipe-flow data, compared with laminar, transitional and turbulent regimes from the Reynolds number.
